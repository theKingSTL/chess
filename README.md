# Battle Chess

Chess where every capture plays a pixel-sprite battle, built on [skill-create-tactics-threejs-sprite](https://github.com/internet-development/skill-create-tactics-threejs-sprite).

Run it: `cd battle-chess && npm install && npm run dev`, then open http://127.0.0.1:5179

Tests: `npm test` (rules, AI, sprites) and `npm run e2e` (Playwright in Edge).
